# Segundo Projeto - 💥 Calculadora de Consumo Elétrico 

Este é um projeto desenvolvido com a linguagem Python, para calcular e estimar o consumo de energia elétrica mensal de aparelhos domésticos com base na potência e no tempo diário de uso.
O programa pede ao usuário alguns dados como: nome do aparelho, potência e o tempo que utiliza em horas.

 💻O cálculo de consumo mensal é feito a partir da seguinte fórmula: consumomensal = (potencia * tempo * 30) / 1000
